CYD PET Radio

Install CYD PET Radio directly from your browser. Choose the option that matches your board and display:

  1. Use Chrome, Edge, or another desktop browser that supports Web Serial.
  2. Connect the board with a USB data cable.
  3. Select the matching board below, then choose its serial port and confirm.

Select the firmware for your exact board and display controller. Display controllers and some board-specific pin configurations differ, so the firmware images are not interchangeable.

Supported boards

CYD 2.8″ ST7789

2.8-inch, 240 × 320 ST7789 TFT display with resistive XPT2046 touch.

CYD 2.8″ ILI9341 (ESP32-2432S028R)

2.8-inch, 240 × 320 ILI9341 TFT display with resistive XPT2046 touch.

Freenove FNK0114L 3.2″

3.2-inch, 240 × 320 ST7789 IPS display with resistive XPT2046 touch.

JC3248W535C_I_Y 3.5″

3.5-inch, 320 × 480 AXS15231B QSPI display with capacitive touch.

On a new install, the flasher may offer to erase the device. Erasing removes the Wi-Fi credentials, station list, volume, and touchscreen calibration. Write down your Wi-Fi credentials before erasing.

After installing, set up Wi-Fi and stations directly on the radio. For hardware notes and setup instructions, see the project repository.
